Como funciona este teste

O protótipo consulta o arquivo data/oportunidades.json do repositório. Quando a automação gerar vagas, elas serão exibidas aqui com os dados efetivamente encontrados.

Nenhuma empresa, vaga, remuneração ou URL é inventada como dado real. Os exemplos ficam identificados como demonstração.
